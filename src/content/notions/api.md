## En clair

Une API est un moyen simple pour permettre à deux applications de communiquer entre elles.

On peut l’imaginer comme une fenêtre de service. D’un côté, une application vient demander quelque chose. De l’autre côté, un service reçoit la demande, cherche l’information et renvoie une réponse.

Par exemple, une application météo ne mesure pas forcément elle-même la température. Elle peut demander à l’API d’un service météo : « Quel temps fait-il aujourd’hui à Colmar ? » L’API récupère alors l’information et lui répond avec la température, la pluie ou les prévisions.

L’API indique aussi précisément comment faire la demande. C’est un peu comme un menu qui précise ce qu’il est possible de commander et la manière de le demander.

Grâce aux API, les applications peuvent partager des informations et utiliser les services les unes des autres, sans avoir besoin de connaître leur fonctionnement intérieur.

En résumé, une API est un intermédiaire qui aide les applications à se parler de manière claire et organisée.

## Pourquoi cette notion est utile ?

Les API sont utiles parce qu’elles permettent aux applications de travailler ensemble.

Grâce à elles, une application peut utiliser un service déjà existant au lieu de tout fabriquer elle-même.

Par exemple, elle peut afficher une carte, proposer un paiement, montrer la météo ou permettre de se connecter avec un autre compte.

Cela fait gagner du temps aux développeurs et permet aux utilisateurs de profiter de davantage de services dans une seule application.

En résumé, les API rendent les applications plus pratiques, plus rapides à créer et plus faciles à connecter entre elles.
